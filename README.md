# Novera

Novera é um FPS de sobrevivência em primeira pessoa, criado para rodar diretamente no navegador.

## Como jogar

- `W`, `A`, `S`, `D`: movimentar
- Mouse: mirar
- Clique esquerdo: atirar
- `R`: recarregar
- `Shift`: correr
- `Esc`: pausar

No celular, jogue com a tela na horizontal usando o controle virtual à esquerda, arraste o lado direito para mirar e use o botão de tiro.

## Objetivo

Sobreviva às ondas de sentinelas, recupere recursos entre as ondas e tente superar seu recorde local.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
