# Novera

Novera é um FPS de sobrevivência em primeira pessoa com arena ampliada, radar tático, progressão por ondas e três armas distintas.

## Arsenal

- `NVR–7`: fuzil automático equilibrado
- `BRK–4`: fuzil de batalha de alto dano
- `VANTA .50`: sniper semiautomática com luneta

## Como jogar

- `W`, `A`, `S`, `D`: movimentar
- Mouse: mirar
- Clique esquerdo: atirar
- Botão direito: abrir a mira / luneta
- `1`, `2`, `3`: selecionar uma arma
- `Q`: trocar para a próxima arma
- `R`: recarregar
- `Shift`: correr
- `Esc`: pausar

No celular, jogue com a tela na horizontal usando o controle virtual à esquerda, arraste o lado direito para mirar e use os botões de tiro, mira, recarga e troca de arma. A sensibilidade pode ser ajustada no menu ou na pausa e fica salva no aparelho.

## Objetivo

Sobreviva às ondas de sentinelas, use o radar para acompanhar os inimigos, recolha munição e kits médicos e tente superar seu recorde local. Os inimigos avisam visualmente antes de atirar e têm limite de ataques simultâneos.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
